# Security and hardware reports

Do not post credentials, private conversation databases or private serial logs in public issues. Use GitHub private vulnerability reporting if enabled; otherwise open an issue without sensitive details to arrange a private report.

The software is an experimental robotics project. Software STOP stops commands/pulses and does not isolate power. The external DM542 enable input is unmanaged in the reference configuration and can retain holding torque. Report the exact hardware and whether a result came from simulation, pulse counting or physical observation.
