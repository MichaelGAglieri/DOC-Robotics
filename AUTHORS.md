# Authorship and project contributions

**Michael Giuseppe Aglieri** — project direction and application idea, five-axis integration of the existing mechanical platform, PETG printing and physical assembly, wiring choices, bench tests, software requirements and iterative validation.

The DOC-specific ROS coordination, simulation scenario, firmware and native macOS application were developed with AI assistance. The project author selected the intended behavior, integrated the components and performed the physical observations described in the project. This is not a claim that every line was manually written, nor a claim of authorship of the original mechanical designs or upstream libraries.

**ToolBox Robotics** designed the original EB-15 arm, EBA actuators and EBG grippers used as mechanical references. **Cyberbotics** supplied the UR3e Webots model from which the five-axis demonstration model derives. **Mike McCauley / AirSpayce** authored AccelStepper. These contributions keep their own authorship and license terms.

The Robot Console icon is an AI-generated illustration supplied by Michael. It is a visual identity asset, not photographic proof of the physical robot or its capabilities. See THIRD_PARTY.md for the scope and source of external components.
