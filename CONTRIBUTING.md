# Contributing

Open an issue describing the problem, the software version and the expected result. For hardware reports include the board, driver, pulse configuration and reducer ratio. Remove credentials, private paths and conversation history from logs.

Use a focused branch and pull request. Include a reproducible test for motion, limits, serial communication or sequence changes. Run the documented tests without attaching a robot. Test results from mocks or simulation must be identified as such; they do not establish physical accuracy or payload capacity.

Contributions to original project code use GPL-3.0-only. Preserve the notices and licenses of third-party material. Do not add downloaded CAD, videos, models or datasets without an explicit source and redistribution review.
