# Validation boundaries

Tests cover the included mathematical model, the simulated transfer contract, command parsing, mission planning, rejection of stale plans and report generation. They use synthetic scene/transport objects where documented. Passing them is not a physical robot acceptance test and is not a new graphical Webots run.

The original development workspace contains prior Webots and bench observations. Raw logs, shopping notes, old archives and unreviewed engineering claims are outside this source release. This repository does not claim a measured payload, grip force, calibrated physical pose accuracy, certified emergency stop, automatic physical homing or collision avoidance on the real arm.

Run the documented test commands on a clean checkout before relying on a change. Record simulator results separately from pulse-count completion and operator observations of actual motion.
